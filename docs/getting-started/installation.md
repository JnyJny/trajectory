# Installation

Trajectory simulator. requires Python 3.14 or later.

## Install from PyPI

The easiest way to install trajectory is from PyPI:

```bash
pip install trajectory
```

## Install from Source

You can also install from source:

```bash
git clone https://github.com/JnyJny/trajectory.git
cd trajectory
pip install -e .
```

## Development Installation

For development, we recommend using `uv`:

```bash
git clone https://github.com/JnyJny/trajectory.git
cd trajectory
uv sync
```

This will install all dependencies including development tools.

## Verify Installation

After installation, verify that trajectory is working:

```bash
trajectory --version
```

You should see the version number displayed.
